## 실제 검증

- Vitest **100/100**, 17파일: 수동 승객 주입·호출 ID·다양한 랜덤 프리셋·애니메이션 보간·데스크톱 경로와 물리 검산·모든 알고리즘 Drain·규모 경계·환승·고장·과부하·재현·snapshot 독립성·종료시각 동시사건·15만 명 대기·통계·내보내기.
- Playwright Chromium **18/18**: 층별/동시 호출·탑승 주황등·1000배 연속 랜덤·100층/20대 가독성·모바일 기본 호출 표시·14개 알고리즘 실제 비교·표본 부족 순위 제외와 설정·재생·정지·초기화·JSON 보존·차트·비교 시간/수요 해시·서로 다른 Drain 종료·설정 왕복·PNG·연구 CSV·Worker·모바일 폭.
- `npm run build`: TypeScript 및 정적 빌드 성공. 기본 진입 JS 약243kB(압축 약79kB), 지연 로드하는 고급 연구 JS 약702kB(압축 약235kB). 고급 연구 청크의 500kB 초과 경고가 남습니다.
- `npm run benchmark`: 증설60회·포화18회와 3케이스 각3회 측정. 환경·시각·시간은 [BENCHMARK](BENCHMARK.md)에 기록합니다. 렌더링·Worker 직렬화는 제외합니다.

- `package:win` / `test:desktop`: EXE폴더/ZIP 생성, 실제 오프라인 호출/탑승/14알고리즘 계산 통과. 오류/HTTP/일반 실행 TCP리스너0. ZIP76파일 및 ASAR내부18파일(프로젝트 MIT 라이선스 포함) 일치. [실행 기록](verification/desktop-smoke.json), [ZIP 검증](verification/desktop-archive-check.json), [ASAR 검증](verification/desktop-content-check.json).

## 의존성 확인

`package-lock.json`에 버전을 고정했습니다. 이전 세션 감사 기록에서 `npm audit --omit=dev`는 발견 0건이고, 개발 의존성 전체에서는 picomatch와 이를 참조하는 도구 6개가 high로 보고되었습니다. 당시 4.0.7에도 패치가 없다고 [GitHub Advisory](https://github.com/advisories/GHSA-fc5q-39xc-vjpf)가 명시합니다. 앱의 사용자 설정은 glob을 입력받지 않으며 개발 서버는 loopback에 바인딩합니다. 호환성을 깨는 강제 downgrade는 적용하지 않았습니다. 패치 제공 시 개발 의존성 업데이트가 필요합니다.

재현 예제는 [examples](../examples/), 설계는 [ARCHITECTURE](ARCHITECTURE.md), 모델 상세 제약은 [ENGINE](ENGINE.md)에 있습니다.

## 최종 추가 검수 (2026-11-18)

- 실제 키보드로 층수/차량 수를 지우고 입력할 때 값이 복원되던 문제를 수정했습니다. 임시 입력값은 Enter/포커스 이동에만 적용하며, 빈값·범위 초과·소수는 기존 설정으로 되돌립니다. 키보드 편집·한계값·랜덤/초기화 동기화 회귀 2개를 추가했습니다.
- 초기 대기열과 동시 수요가 300,000명 상한을 우회하던 문제를 수정했습니다. 초기 수요는 생성 전에 검사하고 모든 자동 수요가 공통 제한을 거칩니다. 정확한 상한 허용·복합 수요 초과 회귀 4개를 추가했습니다.
- 미완료가 남은 종료는 관찰 종료로 표시하고, 수요 설명에서 건물 유형을 가정한 시간대 문구를 제거했습니다.
- 추가 엔진 검수 560회 실행·2,800 snapshot에서 승객 보존·정원·ID·유한 지표·종료/Drain을 확인했습니다.
- 수신자 환경 검수는 ZIP을 한글/공백 경로에 풀고 PATH에서 Node/npm을 제외한 상태로 오프라인 호출·1000배·재시작·연속 랜덤·14개 비교·중복 실행·고급 화면 왕복을 확인했습니다. 기록: [recipient-audit.json](verification/recipient-audit.json).
