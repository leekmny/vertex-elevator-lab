# 반복 실험과 통계

`src/research/runner.ts`의 `runExperiment(config, plan, options)`는 층수 × 차량 수 × 혼잡도 × Seed × 알고리즘을 계산한다. ResearchMode는 별도 모듈 Worker를 사용한다. 한 계획은 40,000회 이하이며 입력을 조용히 자르지 않는다. 중단 요청은 현재 시뮬레이션이 끝난 다음 실행 경계에서 처리한다. 큰 단일 실행의 중단에는 시간이 걸릴 수 있다. 완료된 부분 표본은 `cancelled=true`로 보존한다.

## 공정한 입력

각 건물·차량·혼잡도·Seed에서 승객 기록을 한 번 생성하고 모든 알고리즘에 같은 기록을 전달한다. 수요 난수와 배차 난수는 독립이다. 각 실행에 Seed와 `demandHash`를 보존한다. 해시는 재현성 확인용 FNV-1a이며 암호학적 보증은 아니다. 대응 차이는 같은 건물·차량·혼잡도·Seed·수요 해시만 허용한다.

Destination Dispatch만 탑승 전 목적지를 이용하므로 별도 정보 범주로 표시한다. 서로 다른 정보 범주의 차이는 알고리즘만의 개선으로 해석하면 안 된다.

## 추정량

- 각 Seed의 엔진 지표를 반복 표본으로 삼는다. 승객 전체를 합친 승객 가중 평균과는 다르다.
- 반복 평균, 표본 표준편차(`n−1`), Student t 95% 신뢰구간을 계산한다. 자유도 1~30은 임계값 표, 그 이상은 점근 근사를 쓴다. 적은 반복·비대칭 과부하 분포에서는 주의해야 한다.
- n=1은 구간 추정 불가다. 메모리에서는 무한 구간, JSON에서는 명시적 `null`, UI에서는 `—`로 표시한다.
- 대응 차이 A−B의 구간이 0을 포함하면 차이의 방향을 확정하지 않는다. 다중 비교 보정·p값·자동 우승 선언은 제공하지 않는다.
- 순위는 선택 지표의 수치 정렬이다. 서로 다른 건물·수요 조건의 행을 포함할 수 있으므로 보편적 우열로 해석하면 안 된다.
- 최소 차량 수는 **시험한 조건 중** 평균 대기 95% CI 상한이 목표 이내이고 모든 실행의 미완료가 0인 행에서 고른다. 미시험 대수는 외삽하지 않는다. 여러 조건을 묶은 계획에서 모든 수요 조건의 보장값을 의미하지 않는다.
- 유한 종료 시각의 탑승객도 미완료다. 충분성 분석은 Drain을 고려해야 한다. Drain 한계 도달 시 미완료를 유지한다.

## 확장 및 포화

평균·P95 대기, 처리량, 추정 에너지, 혼잡도×차량 히트맵, 지연 분포와 잔여 대기열 증가율을 실제 실행에서 그린다. 한계 개선은 같은 알고리즘·층수·혼잡도에서 이전의 작은 시험 대수 대비 평균 대기 감소를 대수 차이로 나눈 값이다. 병목 해소율은 최소 시험 대수의 미완료 대비 감소 비율이며, 기준 미완료가 0이면 0으로 표시한다.

`supplyMargin`은 관측 완료/발생 비율−1이다. 공급 설비의 잠재 여유 용량이 아니며 보통 0 이하이다. UI도 관측 완료 비율 차이로 표기한다. 유한 시간 대기열 증가·처리량 곡선은 포화 추세의 관측값이다. 점근적 최대 지속 처리량의 증명이나 연속 수요의 자동 경계 탐색은 제공하지 않는다. 시간·안정화·Seed·수요 구간을 넓혀 수렴을 확인해야 한다.

포화 그래프의 숫자 요약은 선택 건물·최대 시험 대수에서 최대 관측 처리량과, 대기열 증가율의 95% CI 하한이 0보다 큰 최초 시험 혼잡도를 제시한다. 최소 두 혼잡도가 필요하다. 앞선 지점에서 CI 상한이 0 이하인 관측까지 존재하면 두 시험 지점 사이를 관측 구간으로 보고한다. 그렇지 않으면 경계의 하한은 추정하지 않는다. 짧은 실험의 초기 이행 상태도 증가율에 영향을 주므로 이 값은 정상 상태 포화의 증명이 아니다.

## 저장 및 재현

CSV는 UTF-8 BOM·RFC4180 인용과 문자열 수식 이스케이프를 사용한다. 전체 JSON에는 설정·계획·Seed별 지표·수요 해시·불확실성 표기가 있다. HTML 보고서는 외부 서버 없이 열리며 설정과 JSON을 포함한다. 문자열을 HTML 이스케이프한다. PNG는 현재 ECharts의 실제 그래프다.

```powershell
npm run benchmark
```

이 명령은 실제 엔진으로 60회 대수 확장, 18회 포화 실험과 3개 성능 케이스를 실행해 `docs/benchmark.json`, `examples/scaling-config.json`, 전체 JSON·CSV·HTML을 생성한다. 시간은 장비·Node 버전에 의존하며 Worker 직렬화와 렌더링은 제외한다. 생성된 예제는 해당 설정을 전제로 한 추정치다.
